# Database Banking System

Relational database project for a banking information system.

## Technologies

- SQL
- PostgreSQL
- DataGrip

## Project Description

The database models a banking system with entities such as customers,
accounts, transactions, cards and branches.

The project includes:

- Database schema design
- DDL and DML operations
- Complex SQL queries
- Views
- Indexes
- Triggers
- ER diagram
